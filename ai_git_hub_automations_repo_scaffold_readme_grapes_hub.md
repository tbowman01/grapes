# GRAPES-Hub — GitHub Remote AI‑Powered Evaluation Solution

> **codename:** `grapes-hub`  
> **purpose:** A production‑grade template repo for AI‑powered GitHub automations: model/image build & publish, evaluation pipelines, docs site, Pages deploy, optional Wiki, dependency bots, and ADR auto‑index.

---

## ✨ Features
- **Containerized automation runner** (multi‑stage, distroless runtime) published to **GHCR**.
- **Central image reuse** across all workflows.
- **AI eval pipeline** with **Promptfoo** (open source) and baseline metrics artifacts.
- **Security & compliance**: SBOM + Trivy scans, provenance/attestations (optional Cosign hooks), least‑privilege GHA permissions.
- **Docs-as-code** with **Docusaurus** + **GitHub Pages** deploy.
- **ADR auto-indexing** (keeps `docs/adr/README.md` in sync with ADR files).
- **Optional Wiki** support (and docs↔wiki sync helper).
- **Dependency automation**: choose **Dependabot** *or* **Renovate**.
- **Makefile** developer ergonomics, `.env` driven config (no secrets in code).

## 🚀 Quick Start

### 1) Use this template
1. Click **Use this template** → **Create a new repository**.
2. In repo **Settings → Secrets and variables → Actions → Repository secrets**, add:
   - `GHCR_PAT` (if needed; `GITHUB_TOKEN` can publish within same org by default)
   - Any provider keys your evals need (e.g., `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, etc.)

### 2) Copy & edit environment
```bash
cp .env.example .env
# Edit values to suit your org/repo
```

### 3) Build & publish the automation image (locally)
```bash
make image
make push
```
> CI will also build/publish on pushes to `main` and tags, see `.github/workflows/build-image.yml`.

### 4) Run evaluations
```bash
make eval               # local (uses Docker image)
# or in GitHub Actions: see .github/workflows/evaluate.yml
```

### 5) Docs site (Docusaurus)
```bash
make docs-install       # installs docs deps
make docs-dev           # local dev server
make docs-build         # static build in docs/build
```
GitHub Pages deploy runs via `.github/workflows/docs-deploy.yml`.

## 🧰 Makefile Targets
```Makefile
.PHONY: image push eval docs-install docs-dev docs-build sbom scan

image: ## Build automation runner image
	docker build -t $(IMAGE_REGISTRY)/$(IMAGE_OWNER)/$(IMAGE_NAME):$(IMAGE_TAG) \
	  -f containers/automation-runner/Dockerfile .

push: ## Push image to GHCR
	echo "Pushing $(IMAGE_REGISTRY)/$(IMAGE_OWNER)/$(IMAGE_NAME):$(IMAGE_TAG)"
	docker push $(IMAGE_REGISTRY)/$(IMAGE_OWNER)/$(IMAGE_NAME):$(IMAGE_TAG)

sbom: ## Generate SBOM with Syft
	syft $(IMAGE_REGISTRY)/$(IMAGE_OWNER)/$(IMAGE_NAME):$(IMAGE_TAG) -o cyclonedx-json > sbom.json

scan: ## Vulnerability scan with Trivy
	trivy image --scanners vuln $(IMAGE_REGISTRY)/$(IMAGE_OWNER)/$(IMAGE_NAME):$(IMAGE_TAG)

eval: ## Run promptfoo evals
	docker run --rm -v $(PWD)/eval:/work -w /work $(IMAGE_REGISTRY)/$(IMAGE_OWNER)/$(IMAGE_NAME):$(IMAGE_TAG) \
	  npx --yes promptfoo@latest eval -c promptfoo.yaml

docs-install:
	cd docs && npm ci

docs-dev:
	cd docs && npm run start

docs-build:
	node scripts/docs-build.mjs
```

## 🧱 Containers

### `containers/automation-runner/Dockerfile`
```dockerfile
# ---- Build stage ----
FROM node:22-bookworm AS build
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY eval/ ./eval/
# Add any tooling you need for evals (promptfoo is executed via npx at runtime)

# ---- Runtime (distroless) ----
FROM gcr.io/distroless/nodejs22-debian12:nonroot
WORKDIR /work
COPY --from=build /usr/local/bin/node /usr/local/bin/node
COPY --from=build /usr/local/lib/node_modules /usr/local/lib/node_modules
COPY containers/automation-runner/entrypoint.sh /entrypoint.sh
ENTRYPOINT ["/entrypoint.sh"]
```

### `containers/automation-runner/entrypoint.sh`
```bash
#!/usr/bin/env bash
set -euo pipefail
cd /work
exec "$@"
```

### `containers/docs-site/Dockerfile`
```dockerfile
FROM node:22-bookworm
WORKDIR /docs
COPY docs/package.json docs/package-lock.json ./
RUN npm ci
COPY docs/ .
CMD ["npm","run","start"]
```

## 🧾 ADR Auto‑Index

### `scripts/adr-index.mjs`
```js
import {readdirSync, writeFileSync, readFileSync} from 'node:fs';
import {join} from 'node:path';
const dir = 'docs/adr';
const files = readdirSync(dir).filter(f => f.match(/^\d+.*\.md$/)).sort();
const lines = ['# Architecture Decision Records\n'];
for (const f of files) {
  const title = readFileSync(join(dir, f), 'utf8').split('\n')[0].replace(/^#\s*/, '');
  lines.push(`- [${title}](${f})`);
}
writeFileSync(join(dir, 'README.md'), lines.join('\n') + '\n');
console.log('ADR index generated.');
```

## 🧪 GitHub Actions — Key Workflows

### 1) Build & Publish Image — `.github/workflows/build-image.yml`
```yaml
name: build-image
on:
  push:
    branches: [ main ]
    tags: [ 'v*.*.*' ]
  workflow_dispatch:
permissions:
  contents: read
  packages: write
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Log in to GHCR
        uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - name: Build
        run: |
          source .env || true
          docker build -t ghcr.io/${{ github.repository }}/automation-runner:latest -f containers/automation-runner/Dockerfile .
      - name: Push
        run: |
          docker push ghcr.io/${{ github.repository }}/automation-runner:latest
```

### 2) Evaluate — `.github/workflows/evaluate.yml`
```yaml
name: evaluate
on:
  workflow_dispatch:
  pull_request:
    paths: [ 'eval/**', '.github/workflows/evaluate.yml' ]
permissions:
  contents: read
  actions: read
jobs:
  run-evals:
    runs-on: ubuntu-latest
    container: ghcr.io/${{ github.repository }}/automation-runner:latest
    steps:
      - uses: actions/checkout@v4
      - name: Validate env
        run: bash scripts/ci-validate-env.sh
      - name: Run Promptfoo
        working-directory: eval
        run: npx --yes promptfoo@latest eval -c promptfoo.yaml
      - name: Upload results
        uses: actions/upload-artifact@v4
        with:
          name: eval-results
          path: eval/results
```

### 3) Security Scan — `.github/workflows/security-scan.yml`
```yaml
name: security-scan
on:
  schedule:
    - cron: '0 6 * * 1'
  workflow_dispatch:
permissions:
  contents: read
jobs:
  trivy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Pull image
        run: docker pull ghcr.io/${{ github.repository }}/automation-runner:latest
      - name: Trivy image scan
        uses: aquasecurity/trivy-action@0.28.0
        with:
          image-ref: ghcr.io/${{ github.repository }}/automation-runner:latest
          format: 'table'
          exit-code: '1'
          vuln-type: 'os,library'
      - name: Generate SBOM
        uses: anchore/syft-action@v0.17.0
        with:
          image: ghcr.io/${{ github.repository }}/automation-runner:latest
          format: cyclonedx-json
          output: sbom.json
      - uses: actions/upload-artifact@v4
        with:
          name: sbom
          path: sbom.json
```

### 4) Docs Deploy (Pages) — `.github/workflows/docs-deploy.yml`
```yaml
name: docs-deploy
on:
  push:
    branches: [ main ]
    paths: [ 'docs/**', '.github/workflows/docs-deploy.yml' ]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: 'pages'
  cancel-in-progress: true
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '22' }
      - run: npm ci --prefix docs
      - run: npm run build --prefix docs
      - uses: actions/upload-pages-artifact@v3
        with: { path: 'docs/build' }
  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

### 5) ADR Index — `.github/workflows/adr-index.yml`
```yaml
name: adr-index
on:
  push:
    paths: [ 'docs/adr/**', 'scripts/adr-index.mjs' ]
  workflow_dispatch:
permissions: { contents: write }
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '22' }
      - run: node scripts/adr-index.mjs
      - name: Commit changes
        run: |
          if [[ -n $(git status --porcelain) ]]; then
            git config user.name "github-actions"
            git config user.email "actions@users.noreply.github.com"
            git add docs/adr/README.md
            git commit -m "chore(adr): update ADR index"
            git push
          fi
```

## 📝 Optional Wiki
- Enable **Wiki** in repo **Settings**.
- Use `scripts/wiki-sync.sh` if you want to mirror selected docs pages.

### `scripts/wiki-sync.sh`
```bash
#!/usr/bin/env bash
set -euo pipefail
# Example: sync docs/overview.md to wiki Home.md
# Requires: git remote to wiki (auto-created by GitHub when wiki enabled)
WIKI_DIR=.wiki
rm -rf "$WIKI_DIR" && git clone "https://github.com/${GITHUB_REPOSITORY}.wiki.git" "$WIKI_DIR"
cp docs/README.md "$WIKI_DIR"/Home.md
pushd "$WIKI_DIR" >/dev/null
  git add .
  git commit -m "docs: sync to wiki" || true
  git push
popd >/dev/null
```

## 🔒 Security & Compliance Defaults
- **Least‑privilege** workflow permissions.
- **SBOM** generation (CycloneDX) + **Trivy** vuln scan.
- Optional **Cosign** signing/attestations (add to `build-image.yml`).
- **Fail‑fast env validation** in CI (`scripts/ci-validate-env.sh`).

### `scripts/ci-validate-env.sh`
```bash
#!/usr/bin/env bash
set -euo pipefail
missing=0
for var in IMAGE_REGISTRY IMAGE_OWNER IMAGE_NAME IMAGE_TAG; do
  if ! grep -q "^$var=" .env 2>/dev/null; then
    echo "[ERR] Missing $var in .env"; missing=1
  fi
done
if [[ $missing -eq 1 ]]; then
  exit 1
fi
```
