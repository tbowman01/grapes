# Contributing

Thank you for your interest in contributing to GRAPES Hub!

- [Issues](https://github.com/tbowman01/grapes/issues)

- [Discussions](https://github.com/tbowman01/grapes/discussions)

## Code of Conduct

Be respectful, inclusive, and constructive in all interactions.

## Getting Started

1. **Fork** the repository on GitHub
2. **Clone** your fork locally
3. **Set up** your development environment
4. **Create** a feature branch
5. **Make** your changes
6. **Test** your changes
7. **Submit** a pull request

See the full [Contributing Guide](https://github.com/tbowman01/grapes/blob/main/CONTRIBUTING.md) for detailed instructions.

## Development Workflow

```bash
# Set up environment
make setup

# Build container image
make image

# Run tests
make test

# Run linter
make lint

# Format code
make format
```

## Areas for Contribution

### Priority Areas
- Improving evaluation datasets
- Adding new model provider configurations
- Enhancing documentation
- Writing tests
- Improving error handling

### Future Areas
- AI-powered code review features
- Multi-model orchestration
- Web UI development
- Enterprise features

## Commit Message Guidelines

We follow conventional commits:

- `feat: add new evaluation provider`
- `fix: resolve Docker build issue`
- `docs: update README with examples`
- `chore: update dependencies`
- `test: add evaluation test cases`

## Pull Request Process

1. Update documentation if needed
2. Add tests for new features
3. Ensure all tests pass
4. Run linting and formatting
5. Create PR with clear description
6. Link related issues
7. Wait for review
